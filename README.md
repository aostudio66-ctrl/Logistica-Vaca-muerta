# Web App - Cotizador de Logística Industrial para Vaca Muerta

Este proyecto es una aplicación web interactiva diseñada específicamente para el sector de transporte y logística en la cuenca de Neuquén, Argentina. Permite realizar estimaciones tarifarias comerciales rápidas basadas en distancias reales desde el Parque Industrial Neuquén (PIN) hacia puntos clave de la industria energética y minera.

## 🛠️ Tecnologías Aplicadas
- **HTML5:** Estructuración semántica de componentes interactivos.
- **Tailwind CSS:** Diseño responsivo con paleta cromática industrial de alta visibilidad (Slate y Orange).
- **JavaScript Vanila:** Lógica de cálculo matemático en tiempo real y manipulación dinámica del DOM sin librerías externas.

## 🚀 Funcionalidades Clave
1. **Cálculo de Tarifas en Tiempo Real:** Multiplica la distancia del destino seleccionado por los costes operativos fijos de cada tipo de transporte industrial (Tolvas, Carretones, Hot-Shot).
2. **Integración con Canales de Venta:** Genera dinámicamente un enlace de mensajería cifrado utilizando `encodeURIComponent` para enviar automáticamente la orden preformateada al sector de operaciones comerciales.
